# Ajia EPUB Editor 中文使用手册

## 1. 打开书籍

打开在线工具，选择或拖入一本无 DRM 的 `.epub`。文件只停留在浏览器中。打开
之前，编辑器会检查 ZIP 结构、条目路径、声明大小、压缩比、本地文件头、EPUB
package、spine 和目录文件。

“错误”表示输入不安全并停止打开；“提醒”表示可以继续，但存在明确限制；“信息”
说明编辑器采用了安全降级方式。

## 2. 浏览与预览

从“目录”选择章节。预览是隔离的：脚本不会运行，不请求远程资源，链接也会被
禁用。工具栏会显示预览中拦截了多少主动或外部内容。

## 3. 安全修改文字

选择“安全编辑”。只有虚线框内的文字可以修改。可以在同一个文字段中输入、删除、
使用中文输入法或粘贴纯文本。回车、富文本格式、拖放和跨文字段选择会被阻止，
因为这些操作可能改变 XHTML 结构。

每一次被接受的修改都会：

1. 根据当前章节版本重新确认可见文字段；
2. 转义 `&`、`<`、`>` 等 XML 特殊字符；
3. 只替换精确的目标源码范围；
4. 验证完整 XML 与结构指纹；
5. 记录为一次可以撤销的编辑事务。

可以删除完整、独立的文字 token。如果某次修改被拒绝，原文字会立即恢复，界面
和章节切换仍可继续使用。

## 4. 使用 XHTML 源码

必须修改标签本身，或复杂章节不能进入安全编辑时，使用“XHTML 源码”。点击
“验证并应用”提交草稿。无效 XML 只保留为草稿，不会进入预览或导出。“取消本次
输入”恢复最近一次已验证源码；“恢复本章打开时内容”会生成一条可以 Undo 的恢复
记录。

## 5. 查找替换

“查找替换”只搜索正文，不搜索属性、URL、脚本、样式或元数据，也不会猜测跨越
多个 inline text segment 的词组。

- “替换当前”修改一个带章节版本约束的结果；
- “全部替换”先验证所有结果，再一次性提交；任何结果失效时整次操作都不生效；
- 替换文字留空可以安全删除匹配内容。

## 6. 修改目录文字

选择一个可写的 NAV 或 NCX 目录项，修改“目录显示文字”，再点击“更新目录名称”。
只改变 label；链接、fragment、层级和 spine 顺序不变。EPUB 3 NAV 与 EPUB 2
NCX 存在唯一、明确的对应目标时，两份目录会同步更新。

## 7. 撤销、检查与导出

Undo 与 Redo 针对完整编辑事务。导出前点击“检查”；错误会阻止导出，提醒会说明
兼容性风险。

“导出 EPUB”生成新的 `-edited.epub`。编辑器会检查 ZIP `mimetype` 文件头，
比较每个解压 payload 是否等于预期的原始或修改字节，并在下载前重新打开结果。
它永远不会覆盖所选原文件。

## 8. 语言与站内导航

首次打开默认为英文。使用 **EN / 中文** 切换语言，选择只保存在浏览器本地存储。
顶部提供首页、Blog、About 与全部工具入口。

## 9. 支持范围

V0.1 面向可重排、无 DRM 的 EPUB 2 与 EPUB 3。复杂 SVG、MathML、固定版式或
错误章节可能只能预览或编辑源码。ZIP64、旧式非 UTF-8 ZIP 文件名、不安全路径、
超大压缩包和加密内容会被拒绝或保持只读；工具绝不绕过 DRM。

如果发现可能的安全问题，请按 [SECURITY.md](../SECURITY.md) 的方式报告，不要在
公开 Issue 中粘贴书籍内容。
