# Compatibility

Status: Phase 0 baseline.

Compatibility evidence will be recorded by fixture and reader. The initial matrix must include EPUB 2 + NCX, EPUB 3 + NAV, combined NAV/NCX, nested navigation, BOM, relative paths, XML special characters, malformed input, encrypted resources, fixed layout, archive attacks, and large compliant files.

Compliant exported fixtures must be checked with EPUBCheck. Manual reader smoke tests are required before V0.1 release.
